# 第1课：先认识数据，再训练模型

对应指南第1页的“阶段01：基础”。建议先用30-45分钟完成本课；无需提前读完论文。

## 本课只解决三个问题

1. 时间序列是什么？
2. 输入和预测目标怎样从一条长序列中取出来？
3. 滑动平均为什么能让曲线变平滑？

## 1. 先运行，再读代码

在项目根目录的终端运行：

```bash
python3 learning/guide01/lesson01.py
```

结果保存在同级 `outputs/`，重复运行会更新这个目录里的教学结果文件。

- `01_input_target.svg`：历史输入与未来目标的时间范围。
- `02_smoothing.svg`：不同窗口的滑动平均。
- `lesson01_summary.json`：示例样本、数据划分和数值检查结果。

SVG是可以用浏览器直接打开的矢量图。所有曲线都是固定随机种子生成的模拟数据，不是真实ETT数据，不是模型预测。

目录中的PNG是首次默认运行的预览快照；修改参数重新运行后，请以更新的SVG为准。

## 2. 时间序列：顺序就是信息

每小时记录一次温度，会得到按时间排列的数值。

例如：`10, 20, 30, 40, 50, 60, 70`。

如果设置历史长度 `L=3`、预测长度 `H=2`，可以构造3个样本：

| 样本 | 已知历史 X | 未来目标 Y |
|---|---|---|
| 1 | 10, 20, 30 | 40, 50 |
| 2 | 20, 30, 40 | 50, 60 |
| 3 | 30, 40, 50 | 60, 70 |

窗口每次向前移动一个位置。未来目标是训练时拿来纠正模型的“答案”，不是预测时能读取的输入。

打开 `01_input_target.svg`：蓝色是示例样本的48小时历史输入，橙色是后续12小时目标；虚线表示预测开始的边界。本课没有画任何模型预测线。

## 3. 观察值可以包含什么

模拟数据由三部分相加：缓慢上升的趋势、24小时周期波动、随机扰动。

真实数据通常不会告诉我们这三部分各是多少。模型只能从观测到的总和中估计规律。

打开 `02_smoothing.svg`。灰色是观测值；蓝色和橙色分别是7点、25点滑动平均。一个点代表一小时。

本课的平均值取“当前点及之前的若干点”：例如窗口为3，数值为10、20、30，则当前平均值为20。下一小时新来40后，平均值变成30。

- 窗口较小，通常反应较快，但保留更多起伏。
- 窗口较大，通常更平滑，也可能更滞后，并抹去重要变化。
- 平滑曲线不是提前预测的结果，也不保证等于真实趋势。

**与DLinear的区别：**这里使用向后看的移动平均，便于先理解“只能使用过去”。DLinear原实现是在已知的整个历史窗口内做居中的平滑，并进行端点填充。两者的窗口定义和边界处理不同，后面读模型代码时会专门比较。居中平滑只要不读取预测起点之后的真实值，就不必然构成未来信息泄漏。

## 4. 做一次小修改

```bash
python3 learning/guide01/lesson01.py --windows 3 49
```

重新打开平滑图，比较它与原来的7点、25点窗口。窗口大小改变后，模拟原始数据应保持相同，因为随机种子没有变。

然后用下面的命令改变历史和预测长度：

```bash
python3 learning/guide01/lesson01.py --history 24 --horizon 6
```

观察输入/目标图里的时间范围如何改变。这里修改的是任务配置，没有训练或调参。

## 5. 按这个顺序读代码

先看 `make_windows`：怎样把一条序列切成X与Y。

再看 `moving_average`：怎样从一段数值算出平均值；为什么开头不足一个完整窗口时暂不计算。

最后看 `generate_series` 与 `main`：数据怎样生成、划分、检查和保存。画图函数可以暂时跳过。

脚本先按时间把序列划为训练、验证、测试段，再在各段内部构造窗口。这是本课为清楚隔离目标而采用的简化流程；后续ETT实验可以在验证/测试边界之前借用已知历史上下文，但不让未来目标进入训练。
