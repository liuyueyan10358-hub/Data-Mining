# 第1课加练：保留残差中的信息

你已经观察到：大窗口平滑后的曲线主要呈现缓慢走势，而残差里仍然有周期起伏，所以不能把残差全部作为无用噪声丢弃。

## 运行

在项目根目录运行：

```bash
python3 learning/guide01/lesson01b.py
```

默认使用49小时窗口，数据与上一练习使用相同的固定随机种子。

- `outputs/03_trend.svg`：原始观测与估计趋势。
- `outputs/04_residual.svg`：单独展示残差，以及零参考线。
- `outputs/lesson01b_summary.json`：重构误差检查。

PNG（若存在）是默认运行的预览快照。修改参数后查看更新的SVG。

## 核心代码

```python
residual.append(values[index] - trend[index])
reconstructed.append(trend[index] + residual[index])
```

第一行做减法得到残差；第二行加回趋势，检查是否还原原始值。开头没有完整平均窗口的位置保留为None，不参与误差统计。

用温度值40、趋势21举例：残差19；重构为21+19=40。

## 看图时关注什么

1. 原始值高于趋势时，残差为正；低于趋势时，残差为负。
2. 平滑趋势扣除后，残差中仍可见反复起伏，但也混有噪声与趋势估计偏差。
3. 残差不保证均值恰好为0，也不保证每一部分都能预测。

可以再试：

```bash
python3 learning/guide01/lesson01b.py --window 3
```

比较小窗口和大窗口下，哪些变化被分配进了趋势，哪些留在残差里。

## 这与DLinear的关系

本练习只演示分解与重构。DLinear会在分解后，分别用线性层把历史趋势和历史残差映射到未来，再把两个预测相加。

这里的平均是向后看的平均；原版DLinear是在已知历史窗口内部做居中平滑，并使用端点填充。后续阅读原模型时会比较两种定义。

## 完成标准

能够解释：为什么重构误差接近0，只说明已知数据被正确拆分和相加，并不能证明模型有预测未来的能力。
