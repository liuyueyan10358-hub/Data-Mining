## 现在从哪里开始

打开 [第1课：认识时间序列](learning/guide01/README.md)。这一课只观察模拟数据，不训练模型。

```bash
python3 learning/guide01/lesson01.py
```

脚本只使用 Python 标准库，不需要先安装 PyTorch、NumPy 或显卡环境。
